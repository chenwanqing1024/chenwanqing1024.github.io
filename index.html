Wanqing Chen

研究员 × 工程师 · AI · 数据 · 系统

软件工程师，专注于在研究创新与生产工程之间搭桥。我设计并构建生产级 AI 应用 — Agent 架构、RAG 流水线、MCP 集成工具、LLM 驱动的工作流。同时在大数据基础设施（基于 Flink / Paimon 的实时 + 离线数仓）和后端工程（JVM 调优、分布式系统）方面有深厚积累。

我相信工程严谨性 — 可观测性、可测试性、可运维性 — 才是把 AI demo 变成可靠产品的关键。从 prompt 设计到分布式流水线，我关注整条链路：研究思路 → 工程实现 → 生产部署。

目前常驻中国深圳，工作横跨 AI/Agent 系统与大规模数据平台。生产代码主要用 Java、Python、SQL，对数据产品的完整生命周期 — 从架构建模到实时流式与离线批处理 — 有端到端的实战经验。

在 GitHub 上维护开源项目并分享工程笔记。期待在 AI/Agent 工具、数据基础设施、以及一切能把研究带到生产的事情上合作。
