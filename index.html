Wanqing Chen

研究员 × 工程师 · AI · 数据 · 系统

Wanqing Chen 是一名研究员型工程师，专注于在研究创新与生产工程之间搭桥。他的工作横跨三个方向：生产级 AI 系统（Agent 架构、RAG 流水线、MCP 集成工具、LLM 驱动的工作流）、大数据架构（基于 Flink / Paimon 的实时与离线一体化数仓），以及 Java 后端工程（JVM 调优、分布式系统设计）。

凭借 8 年研究员与工程师的双重一线经验，他把深度技术能力与产品思维结合在一起 — 从算法设计和系统架构，到交付真正解决问题的生产级方案。

他相信工程严谨性 — 可观测性、可测试性、可运维性 — 才是把 AI demo 变成可靠产品的分水岭，因此关注的始终是完整链路：研究思路 → 工程实现 → 生产部署。他用 Java、Python、SQL 写生产代码，对数据产品的完整生命周期 — 从架构建模到实时流式与离线批处理 — 有端到端的实战经验。

目前常驻中国深圳。他在 GitHub 上维护开源项目、持续输出工程笔记，相关沉淀整理在作品页。欢迎就 AI/Agent 工具、数据基础设施，以及一切能把研究带到生产的方向交流合作。
