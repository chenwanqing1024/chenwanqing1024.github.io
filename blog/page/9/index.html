十年之后

2026-09-14 AI 未来 随笔

从 2036 年往回看——AI 时代的真正变化不在能力跃迁，而在社会吸收的速度。我们 2026 年关于 Agent、白领失业、AGI 的预测，几乎全错了。错的部分比对的部分更值得讲。

蹬掉 10 个订阅不难，难的是把自己 scale 起来 读文笔记

2026-09-14 AI Codex Agent 自动化 复利 读文笔记

冯若航把"如何凑齐 10 个 200 美元 Codex 订阅"拆成两层：买得到是技术活，蹬得完是体系活。订阅费从来不是瓶颈，能持续堆出可被 AI 自动化的手工活、搭出能自己运转的复利体系、把验收范式从细节转向宏观——这才是真正的稀缺资源。

文档驱动：AI 工程的护城河不在代码，在文档 读文笔记

2026-09-14 Agent AI 工程 文档驱动

冯若航把 AI 软件工程的四条核心做法中的第一条——文档驱动——从"代码的补充"重定位为"代码的输入、工作记忆与验收凭据"。认同文档前置的方向，但 push back 两条：70-80% Token 用于 QC 的比例被简化、"每个 Issue 一份设计文档"的边界没说清；并扩展到 MCP/schema/ADR 这条隐线。

AGI 机关枪发下来了，可谁来验收 读文笔记

2026-09-14 AI Agent 读文笔记 工程判断

老冯把"AGI 机关枪"叙事推到极致，但最锋利的不是"门外汉也能烧"，而是"代码无限、信任不无限"和 80/20 法则——稀缺的是 selection（知道什么值得做）和 acceptance（知道哪里可能有问题），不是 execution；蒋老板的"门外汉"其实是"有品味的门外汉"，这条叙事张力文章没解开。

Agent 是第三个数据外泄点 读文笔记

2026-09-14 Agent 本地 AI 数据主权 MCP

冯若航把"本地 AI"框定为政治账而非经济账。这篇认同他的核心论点，但把推论再往前一步：Agent 不是模型问题的延续，而是突变——它把数据外泄从"事实"和"意图"两个维度扩展到了"动作"，并让"数据分级"这条建议在工程上变得不再可行。
