LangGraph 3 年：什么时候用 graph / 什么时候用 harness / 什么时候用 loop——决策框架 读文笔记

2026-09-15 Agent LangGraph 工程哲学 决策框架 工程实践

LangGraph 3 年的核心经验：什么时候把 Agent 表达为 graph（结构已知、路径确定）、什么时候用 agent harness（结构未知、靠模型推理）、什么时候用 loop（最简版本）。3 个关键 lesson：agent graph 通常不是 DAG、loop 就是简单 graph、动态 transition 重要。附决策框架 + 简历项目骨架。
